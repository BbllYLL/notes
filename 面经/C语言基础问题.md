# 说一下 const、volatile、static 的作用和典型使用场景？
## 【考察点】
	C 关键字理解 
	嵌入式中对寄存器、共享变量、模块封装的掌握
## 【答题思路】
	先分别定义这三个关键字
	再结合嵌入式场景给出例子
## 【示范回答】

const 表示“只读”，通过这个标识符不能修改变量的值。嵌入式中常用来修饰： 
	查表数据、配置参数，防止误修改； 
	函数参数，表达“我不会在函数内改这个参数”。

volatile 告诉编译器，这个变量的值可能会在程序之外被改变，比如被 中断或者硬件修改，所以每次使用都必须从内存重新读取，不能用寄存器 缓存。典型场景有：
	中断与主程序之间共享的标志位； 
	映射硬件寄存器的指针。

static 主要有两个作用： 
	修饰局部变量时延长生命周期到整个程序运行期，适合计数器、状态机变量； 
	修饰全局变量和函数时，把作用域限制在当前源文件，实现模块内封装。

在嵌入式项目中，这三个关键字用得非常多，不仅影响程序行为，也关系 到可读性和可维护性。
## 【加分点】
	能举出 volatile uint32_t * const p = (uint32_t *)0xXXXX; 这类寄存器指针例子
	能说出 const 影响的是“通过这个名字不能改”，但底层内容可能还是会变（比如被硬件改）
